    Guide for teachers and admins

    How the club website works, how to run a session, and how to grow it.

    Who can do what

    • Students use the labs, take exams, see their progress and collect certificates.
    • Teachers create student logins, build and publish exams, read results and post notices.
    • The admin also adds labs and subjects, manages teacher accounts and changes roles.

    How progress is counted

    A lab is started when a logged-in student opens it, and completed after about 2 minutes of real use (with at least 10 actions in built-in simulations). Time only counts while the student is active on the page.

    Running a club session

    1. Open one lab on the classroom screen and ask students to predict what will happen.
    2. Let pairs try it on phones or school computers, changing one thing at a time.
    3. Finish with a short published exam, then check the question analysis to see what to teach again.

    Safety first

    The chemistry lab shows reactions virtually. Real acids, alkalis, silver nitrate and copper sulfate need goggles, gloves and a teacher.

    AI tutor

    Logged-in students can press Ask the tutor on any lab page. The tutor knows which subject and lab they are on, guides them with hints instead of just giving answers, and replies in Amharic when asked in Amharic. The admin sets daily limits and can switch it off per subject (Admin → AI tutor and Admin → Subjects). Teachers can also use Write questions with AI in the exam builder, then check the questions before publishing.

    Coding lab

    Students write real Python in the browser, with no installation. Coding exercises check answers automatically and count towards certificates. The Python playground has examples with graphs. To add an exercise: Admin → Labs → Add a lab → Coding exercise, then write the starting code and one check per line.

    Adding labs without code

    Admin → Labs → Add a lab. Paste a link to a free simulation (for example from PhET or GeoGebra) or write a hands-on guide with numbered steps.

    Adding a coded simulation

    Copy a file in assets/js/sims/, change it, and add one <script> line in index.html. After publishing, open Admin → Labs and press Add them to the site.

    Classes

    Each class has a join code. Students type the code on the Classes page, or when they create their account. In a class, teachers post announcements and classwork (courses, labs, exams, assignments, materials) with due dates, and see a gradebook. Students see their to-do list on their dashboard.

    Courses

    Teachers build courses from lessons. A lesson can contain text, a video, links, one of the labs and an exam. Students tick off lessons, hand in assignments and see their marks and feedback. Each course has a progress report.

    Going live

    Until the database is connected, the site runs in demo mode, saving everything in one browser. Follow SETUP.md, then open the setup check. It shows what is missing and creates the admin account.
